SEIW — ЗАЩИЩЁННЫЙ ВХОД В WINDOWS
=================================

SEIW — программа, которая ставит между человеком и рабочим столом привычный
экран входа в стиле Windows, но с защитой от подглядывания.

Главная особенность — «спящие» символы: поле пароля принимает любые нажатия
(латинские буквы, цифры, случайные знаки), но видимость знаков отсутствует —
всегда показываются только точки. К доступу ведёт последовательность «живых»
знаков (тех, что входят в пароль) среди всех набранных, поэтому лишние символы
можно вводить в любом месте и любом порядке — они не мешают. Русские буквы в
пароле не участвуют: ввод идёт латиницей и цифрами, интерфейс английский.

ЧЕСТНОЕ ПРЕДУПРЕЖДЕНИЕ
----------------------

Система НЕ защищает от записи ввода на видеокамеру и от перехвата нажатий
клавиш (логирование клавиатуры). Если злоумышленник зафиксирует всю
последовательность нажатий целиком и повторит её — доступ будет открыт.
Защита рассчитана на одиночное подглядывание, а не на полную видеозапись
ввода.

ПРИМЕНЕНИЕ
----------

Универсальный защищённый вход, подходит для разных сценариев:
- кабинет руководителя и рабочие станции;
- госслужба и работа с конфиденциальными данными;
- родительский контроль времени на ПК (одно из применений).

СОСТАВ РЕПОЗИТОРИЯ
------------------

  SEIW        - основное приложение: экран входа, смена пароля, настройка, обои
  SEIWCore    - общая библиотека: пользователи, пароли, расписание, IPC
  SEIWGuard   - Windows-служба «замок сверху» (SYSTEM) - дополнительный экран
  LockAgent   - агент-замок, запускается службой в каждой активной сессии
  site        - лендинг/карточка продукта (загрузка на хостинг)

Подробнее о службе-замке — в файле README-SEIWGuard.md (README-SEIWGuard.txt).

СБОРКА
------

Требуется .NET 8 SDK. Из корня репозитория:

  dotnet build SEIW\SEIW.csproj -c Release
  dotnet build LockAgent\LockAgent.csproj -c Release
  dotnet build SEIWGuard\SEIWGuard.csproj -c Release

ПЕРВЫЙ ЗАПУСК
-------------

1. Запустите SEIW.exe.
2. При первом запуске программа создаст учётную запись «Администратор».
3. Задайте свой пароль (латиница и цифры) — программа предложит сменить
   начальный пароль при первом входе.
4. При необходимости добавьте программу в автозагрузку, чтобы экран входа
   поднимался сразу при включении компьютера.

ЗАЩИТА ОТ ПОДГЛЯДЫВАНИЯ - «СПЯЩИЕ» СИМВОЛЫ
------------------------------------------

Поле пароля принимает любые нажатия, но видимость знаков отсутствует (только
точки). Доступ открывает последовательность «живых» знаков среди всех
набранных. Тот, кто подглядывает один раз или подбирает пароль «наугад», не
знает, какие знаки настоящие, и не сможет повторить вход.

БЕЗОПАСНОСТЬ
------------

- Хеширование пароля — Argon2id (OWASP-рекомендация, параметры m=19 МиБ,
  t=2, p=1). Никакого одноразового SHA-256.
- Код восстановления — хранится только в виде Argon2id-хеша, не в открытом
  виде.
- Допуск — вход по последовательности «живых» знаков, лишние знаки в любом
  порядке допускаются.
- Лимит попыток — после 5 неверных попыток поле блокируется на 30 секунд.
- Хранение на диске — файлы пользователей находятся рядом с программой;
  рекомендуется ограничивать доступ к папке установки. Программа работает
  локально и не собирает данные.

ВОССТАНОВЛЕНИЕ ПАРОЛЯ
---------------------

На экране входа есть «Забыли пароль»: введите ключ восстановления (латиница
и цифры) — зададите новый пароль.
