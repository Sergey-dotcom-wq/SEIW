# SEIW — защищённый вход в Windows

**SEIW** — программа, которая ставит между человеком и рабочим столом привычный
экран входа в стиле Windows, но с защитой от подглядывания.

Главная особенность — **«спящие» символы**: поле пароля принимает любые
нажатия (латинские буквы, цифры, случайные знаки), и всё введённое видно, но
к доступу ведёт только верная комбинация знаков. Русские буквы в пароле не
участвуют — ввод идёт латиницей и цифрами, интерфейс английский. Подсмотреть
пароль по рукам, взгляду или камере — бесполезно.

## Применение

Универсальный защищённый вход, подходит для разных сценариев:

- кабинет руководителя и рабочие станции;
- госслужба и работа с конфиденциальными данными;
- родительский контроль времени на ПК (одно из применений).

## Состав репозитория

| Проект        | Назначение                                                          |
|---------------|---------------------------------------------------------------------|
| `SEIW`        | Основное приложение: экран входа, смена пароля, настройка, обои    |
| `SEIWCore`    | Общая библиотека: пользователи, пароли, расписание, IPC            |
| `SEIWGuard`   | Windows-служба «замок сверху» (SYSTEM) — дополнительный экран       |
| `LockAgent`   | Агент-замок, запускается службой в каждой активной сессии           |
| `site`        | Лендинг/карточка продукта (загрузка на хостинг)                    |

Подробнее о службе-замке — [README-SEIWGuard.md](README-SEIWGuard.md).

## Сборка

Требуется .NET 8 SDK. Из корня репозитория:

```
dotnet build SEIW\SEIW.csproj -c Release
dotnet build LockAgent\LockAgent.csproj -c Release
dotnet build SEIWGuard\SEIWGuard.csproj -c Release
```

## Первый запуск

1. Запустите `SEIW.exe`.
2. При первом запуске программа создаст учётную запись «Администратор».
3. Задайте свой пароль (латиница и цифры) — программа предложит сменить
   начальный пароль при первом входе.
4. При необходимости добавьте программу в автозагрузку, чтобы экран входа
   поднимался сразу при включении компьютера.

## Защита от подглядывания — «спящие» символы

Поле пароля принимает любые нажатия, и всё введённое отображается. Но к
доступу ведут только символы, которые входят в настоящий пароль. Тот, кто
наблюдает за руками, взглядом, записью клавиатуры или камерой, видит все
нажатия — и всё равно не сможет повторить вход.

## Восстановление пароля

На экране входа есть «Забыли пароль»: введите ключ восстановления
(латиница и цифры) — зададите новый пароль.

## Системные требования

- .NET Desktop Runtime 8.0.
