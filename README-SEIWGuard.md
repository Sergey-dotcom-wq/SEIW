# SEIWGuard — «замок сверху» для Windows

Служба, которая показывает экран-замок поверх рабочего стола в активной сессии
Windows. Помогает родительскому контролю SEIW работать как «замок на весь
компьютер», не трогая стандартный вход в систему.

## Важно: служба НЕ заменяет стандартный вход Windows

SEIWGuard **не подменяет** экран входа Windows (Winlogon), не перехватывает
Ctrl+Alt+Del и не вмешивается в логин при включении. Системный вход и пароль
учётной записи Windows остаются полностью родными и работают как обычно.

Служба лишь добавляет **дополнительный экран-замок поверх рабочего стола** уже
вошедшей сессии. Это «замок сверху», а не замена системного механизма.

## Всегда можно перейти на стандартный вход

- **Остановить службу:** `sc stop SEIWGuard` — замок исчезнет сразу, Windows
  работает как обычно.
- **Удалить службу:** `sc delete SEIWGuard` (после `sc stop`) — полностью убрать.
- Служба не мешает обычному входу, выключению и переключению пользователей.

## Состав

| Проект       | Назначение                                                        |
|--------------|-------------------------------------------------------------------|
| `SEIW`       | Основное приложение (экран входа, настройка, расписание)          |
| `SEIWCore`   | Общая библиотека (пользователи, пароли, расписание, IPC)          |
| `SEIWGuard`  | Windows-служба «замок сверху» (SYSTEM)                            |
| `LockAgent`  | Агент-замок, запускается службой в каждой активной сессии          |

## Сборка

Требуется .NET 8 SDK. Из корня:

```
dotnet build SEIW\SEIW.csproj -c Release
dotnet build LockAgent\LockAgent.csproj -c Release
dotnet build SEIWGuard\SEIWGuard.csproj -c Release
```

## Установка службы (от администратора)

```
SEIWGuard.exe --install
sc start SEIWGuard
```

`--install` скопирует `LockAgent.exe` рядом со `SEIWGuard.exe` (служба запускает
агента в каждой сессии) и создаст службу с автозапуском.

Проверить, что служба работает:

```
sc query SEIWGuard
```

## Удаление

```
sc stop SEIWGuard
SEIWGuard.exe --uninstall
```

## Запуск без службы (отладка)

```
SEIWGuard.exe --interactive
```

## Поведение по расписанию

Служба читает `seiw_schedule.json` (создаётся в папке, где запущена программа).
Интервалы: `Lock` (держать замок), `Shutdown` (выключить после предупреждения),
`Message` (показать текст). Пароль и кодовое слово — из `seiw_users.json`.

## Безопасность и открытый код

Исходный код под лицензией MIT. Служба не собирает данные и работает локально.
Отключение службы всегда возвращает стандартный вход Windows без каких-либо
последствий.
